This report covers the standalone Android preview on the owner's authorised Android TV 11 TCL. It is not household integration acceptance or all-TV verification. Network addresses and raw diagnostics are retained privately.

## Findings and fixes

1. Native Settings buttons initially had weak focus visibility. Added a clear light focused background, dark text, outline and initial control focus, with matching pressed state. Visually verified on the TCL in a temporary device-check build, including Down selecting the next connection button.
2. Saving reordered shortcuts stored their order but left an old numeric focus position. Save now stores the current focus index atomically with the layout. Extended the recreation regression test to assert that the moved shortcut retains focus, then verified that same shortcut stays focused after force-stop/relaunch on the TCL in the updated device-check build.

The local debug key differs from the earlier CI key, so an in-place update was correctly refused without changing the installed preview. The deviceCheck build type provides an isolated temporary package for hardware checks and avoids deleting the CI preview's configuration. Stable private signing is still required for a dependable cross-build update channel. Never uninstall a household-configured preview just to bypass this mismatch without preserving its configuration and owner approval.

## Measurements and limits

Observed cold launch samples ranged approximately 2.7 to 7.4 seconds across test builds and states; the initial CI cold start was 5.48 seconds. A hot task return measured 620 ms. These are sparse Android activity timing samples, not p95 measurements or a completed performance gate. One process memory snapshot reported 53,223 KB total PSS. No memory budget or leak-free endurance claim follows from it.

Local debug unit tests, lint and assembly passed after both fixes. Device-check assembly also passed. Current GitHub Actions result must be read for the corresponding commit; the earlier successful run does not validate later changes.
