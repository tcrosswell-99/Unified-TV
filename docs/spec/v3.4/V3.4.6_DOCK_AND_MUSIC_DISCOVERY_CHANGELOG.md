# v3.4.6 — Dock size and music app discovery

- Dock capacity: **6 default**, **8 optional**; per-profile setting, safe layout, no automatic extra apps.
- Focused-only labels remain the default for either capacity.
- One installed music app: auto-select without prompting; multiple: ask for default and one/both/all visibility; none: optional guided choice; detection unknown: manual choice.
- Multiple music apps may occupy separate dock slots or remain in Apps; never overwrite full dock without confirmation.
- No silent installs, sideloading, store bypass or unsupported availability promises.
- Specification only; implementation and physical-TV testing remain outstanding.
